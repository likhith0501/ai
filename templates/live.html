📺 Real sensor instead of replay? (capture live traffic from your own machine)
The sensor reads flow metadata only (5-tuple, counters, timings) — payloads are never assembled or stored. Capture traffic only on machines and networks you are authorised to monitor. Windows needs Npcap plus an Administrator terminal; Linux needs root or CAP_NET_RAW.
1. List interfaces
python utils/live_sensor.py --list-interfaces
2. Capture and score (terminal alerts, no upload needed)
python utils/live_sensor.py --iface Wi-Fi --seconds 120 --csv captures/live.csv
3. Stream the verdicts into this dashboard
python utils/live_sensor.py --iface Wi-Fi --api http://127.0.0.1:5000/api/sensor/sample

Captured flows appear above as analyses named live-sensor::<interface> and are scored by the same model.
