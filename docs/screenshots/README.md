# Screenshots

The README references these images. Capture them from a local run and save them here:

| File | How to capture |
| --- | --- |
| `home.png` | `http://127.0.0.1:5000/` |
| `upload.png` | `/upload` after selecting a CSV (preview panel) |
| `dashboard.png` | `/dashboard` after analysing a dataset |
| `results.png` | `/results/<id>` |
| `metrics.png` | `/metrics` |
| `live.png` | `/live` with the simulation running |

Run the project first:

```bat
python training/train.py
python app.py
```
